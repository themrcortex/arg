## اصطلاحات

| اصطلاح | معنی |
| --- | --- |
| API | رابط برنامه برای تبادل درخواست/پاسخ ساختاریافته |
| ARG Helper | سرویس جدا با دسترسی root که فقط عملیات allowlist را اجرا می‌کند |
| Audit | تاریخچهٔ رویدادهای مدیریتی ثبت‌شده در ARG |
| Bind address | آدرس/رابطی که سرویس روی آن گوش می‌دهد؛ `127.0.0.1` محلی و `0.0.0.0` همهٔ IPv4هاست |
| Bucket | مخزن Object در S3-compatible storage |
| Cache | دادهٔ موقت برای سرعت؛ ممکن است دیسک را اشغال کند و قابل پاک‌سازی باشد |
| cgroup | سازوکار کرنل برای اندازه‌گیری یا محدودکردن منابع گروه process |
| FUSE | پیاده‌سازی فایل‌سیستم در userspace؛ S3 mount معادل کامل POSIX نیست |
| Image / Container | قالب Docker و نمونهٔ در حال اجرای آن |
| Listener | سوکتی که منتظر اتصال روی آدرس/پورت است |
| Mount point | مسیر نمایش یک فایل‌سیستم در درخت مسیرهای لینوکس |
| Object / Prefix | داده و کلید S3؛ Prefix فقط شکل پوشه‌ای نام را می‌سازد |
| Origin validation | محدودکردن درخواست تغییر وضعیت به origin مورد انتظار مرورگر |
| PTY | pseudo terminal برای اجرای تعاملی shell و برنامه‌ها |
| Rollback | بازگردانی باینری/دیتابیس قبلی ذخیره‌شده؛ جایگزین backup مستقل نیست |
| RPO / RTO | حداکثر دادهٔ قابل‌از‌دست‌رفتن و زمان بازیابی هدف |
| TLS | رمزنگاری ارتباط؛ HTTPS یعنی HTTP روی TLS |
| UFW | ابزار سادهٔ مدیریت firewall مبتنی بر netfilter در Ubuntu/Debian |
| systemd unit | تعریف سرویس/زمان‌بند و سیاست اجرای process در Linux |
