# API عمومی فقط‌خواندنی

نسخهٔ اول API عمومی، خلاصهٔ اپلیکیشن‌ها و استقرارها را برای ابزار گزارش‌گیری و داشبورد بیرونی ارائه می‌کند. این API راه عمومی مدیریت پنل نیست.

## مرز امنیتی

- کلیدها پیشوند `arg_live_` و ۲۵۶ بیت دادهٔ تصادفی دارند.
- ARG فقط هش SHA-256 را نگه می‌دارد. توکن خام فقط یک‌بار هنگام ساخت نمایش داده می‌شود و بعداً قابل بازیابی نیست.
- مدیریت کلید برای مدیر در **مدیریت سرور و ARG ← کلیدهای API عمومی** قرار دارد.
- هر مدیر حداکثر ۱۰ کلید فعال می‌تواند داشته باشد. انقضا اجباری و بین ۱ تا ۳۶۵ روز است.
- صدور کلید و استفاده از API فقط با HTTPS مجاز است. کلید را در URL، Query String، مخزن کد، Local Storage مرورگر یا Log قرار نده.
- Scope تمام کلیدها فعلاً ثابت است: `apps:read` و `deployments:read`. هنوز امکان محدودکردن کلید به Project، Workspace یا VPS مشخص وجود ندارد؛ فقط به اتصال قابل‌اعتمادی کلید بده که مجاز است خلاصهٔ همهٔ اپلیکیشن‌ها و استقرارهای همین نمونهٔ ARG را بخواند.
- سقف هر کلید ۶۰ درخواست در دقیقه است. Service Worker پنل پاسخ‌های API را Cache نمی‌کند.

## ساخت کلید

۱. با HTTPS و حساب مدیر وارد شو.
۲. از سایدبار **مدیریت سرور و ARG** را باز کن و کارت **کلیدهای API عمومی** را پیدا کن.
۳. نامی مشخص و اعتبار ۱ تا ۳۶۵ روز وارد کن و کلید بساز.
۴. توکن داخل پنجرهٔ یک‌باره را در Secret Manager قابل‌اعتماد ذخیره کن. با بستن پنجره، مقدار خام از State مرورگر پاک می‌شود.
۵. توکن را فقط در هدر `Authorization: Bearer` بفرست.

## دریافت فهرست اپلیکیشن‌ها

```sh
curl --fail-with-body --silent --show-error \
  -H "Authorization: Bearer ${ARG_TOKEN}" \
  "https://arg.example/api/v1/apps?limit=50&offset=0"
```

پاسخ شامل شناسه و نام اپ، چارچوب، نسخهٔ Runtime ثبت‌شده، دامنه، وضعیت مورد انتظار و مشاهده‌شده، چرخهٔ عمر و زمان آخرین تغییر است. متغیرهای محیطی، تنظیم منبع، Secret reference یا Credential برگردانده نمی‌شود.

## دریافت استقرارها

```sh
curl --fail-with-body --silent --show-error \
  -H "Authorization: Bearer ${ARG_TOKEN}" \
  "https://arg.example/api/v1/deployments?limit=50&offset=0"
```

پاسخ شامل Job ID، شناسه و نام اپ، وضعیت، Commit منبع و زمان‌های چرخهٔ اجراست. `source_json` و جزئیات کامل خطا حذف شده‌اند چون ممکن است اطلاعات مخزن خصوصی یا محیط را داشته باشند.

## صفحه‌بندی و خطاها

`limit` پیش‌فرض ۵۰ و در بازهٔ ۱ تا ۱۰۰ است. `offset` پیش‌فرض صفر و در بازهٔ صفر تا ۱٬۰۰۰٬۰۰۰ محدود می‌شود. پاسخ فیلدهای `data` و `pagination` را با مقدار مؤثر و تعداد ردیف برگشتی دارد.

| کد | معنی |
| --- | --- |
| `400` | درخواست یا مقدار صفحه‌بندی نامعتبر |
| `401` | کلید موجود نیست، منقضی/لغو شده یا اشتباه است |
| `403` | HTTPS لازم است یا کلید Scope لازم را ندارد |
| `429` | سقف ۶۰ درخواست در دقیقه برای کلید رد شده است |
| `500` | خطای داخلی سرویس یا پایگاه‌داده؛ درخواست را پیوسته و سریع تکرار نکن |

## لغو و تعویض کلید

در جدول کلیدها، دکمهٔ لغو را برای کلید قبلی بزن. لغو در درخواست بعدی اثر می‌کند و قابل بازگشت نیست. ابتدا کلید جایگزین را بساز و Secret اتصال را عوض کن؛ بعد کلید قبلی را از ابزار بیرونی پاک کن. توکن خام از ARG بازیابی نمی‌شود.

## سند OpenAPI

قرارداد ماشینی در `GET /api/v1/openapi.json` بدون توکن قابل دریافت است. سند فقط endpointهای خواندنی فعلی را توصیف می‌کند و وعدهٔ API نوشتنی، Webhook، Scope مستاجر یا endpoint آینده نیست.

## محدودیت‌های فعلی

این API فقط‌خواندنی و محدود به همان نمونهٔ ARG صادرکنندهٔ کلید است. Scope نوشتن، ارسال Webhook، انتخاب Project برای کلید، سهمیهٔ جدا برای tenant، خروجی Audit و SDK تولیدشده هنوز وجود ندارند. تا آماده‌شدن جداسازی تیم/مستاجر، کلید گسترده را میان مشتری‌ها تقسیم نکن.
