## ARG در یک نگاه

ARG یک کنترل‌سنتر خودمیزبان برای مدیریت VPS لینوکسی است. پنل در مرورگر اجرا می‌شود، اما عملیات سیستم را Backend نوشته‌شده با Rust انجام می‌دهد. رابط وب با React و TypeScript ساخته شده و صفحه‌ها برای کارهای عملیاتی طراحی شده‌اند: خواندن وضعیت، تغییر پیکربندی، اجرای عملیات محدودشده و دیدن نتیجه.

ARG جایگزین پنل ارائه‌دهندهٔ VPS، سامانهٔ مانیتورینگ سازمانی، سامانهٔ پشتیبان‌گیری مستقل یا ابزار مدیریت چندسروری نیست. دادهٔ واقعی فقط وقتی نمایش داده می‌شود که سیستم‌عامل یا سرویس مربوط آن را گزارش کند. قابلیت‌های برنامه‌ریزی‌شده در این راهنما به‌عنوان قابلیت موجود معرفی نمی‌شوند.

## قابلیت‌های موجود

- داشبورد و ثبت پس‌زمینهٔ تاریخچهٔ CPU، حافظه، دیسک و نرخ ترافیک شبکه در SQLite.
- فهرست رابط‌های شبکه، پورت‌های شنونده و ابزار تست اتصال TCP محلی.
- مدیریت UFW، قانون‌های TCP/UDP و پورت‌های محافظت‌شدهٔ SSH و ARG.
- مدیریت سایت‌های Nginx، کانفیگ، وضعیت، دامنه، SSL، حالت تعمیرات، اکشن‌های اختصاصی و محدودیت منابع سرویس‌های مستقل.
- مدیریت Docker/Compose و منابع موجود Engine؛ عملکردهای خطرناک با عملیات تأییدی انجام می‌شوند.
- فایل‌منیجر سیستم با بارگذاری/دریافت، عملیات فایل، ZIP امن و تحلیل مصرف دیسک.
- اتصال S3-compatible، مرور Object، انتقال بین دیسک و Bucket و بررسی مصرف Bucket.
- مدیریت پایه MySQL/MariaDB، کاربران دیتابیس، اجرای SQL کنترل‌شده و بازیابی رمز.
- APT، سرویس‌های systemd، ترمینال، کاربران پنل، نشست‌ها، گزارش Audit و ابزار پشتیبان/بازیابی ARG.

جزئیات محدودیت هر بخش در صفحهٔ همان قابلیت نوشته شده است. برای مثال، فضای S3 فقط زمانی ظرفیت کل دارد که Provider آن را گزارش کند؛ در غیر این صورت سقف «نامشخص» است و مصرف از پیمایش Objectها محاسبه می‌شود.

## اصول طراحی

1. **دادهٔ معتبر:** مقدار نامعلوم به‌صورت «نامشخص» گزارش می‌شود و با صفر یا دادهٔ نمونه جایگزین نمی‌شود.
2. **مرز دسترسی:** عملیات عادی در Backend Rust اعتبارسنجی می‌شود. کارهای روتی فقط از طریق Helper محدود و فهرست‌شده انجام می‌شوند.
3. **تغییر قابل‌ردیابی:** عملیات مدیریتی در Audit ثبت می‌شوند؛ گذرواژه، کلید و محتوای محرمانه نباید در لاگ قرار گیرند.
4. **بازگشت‌پذیری:** به‌روزرسانی پنل باینری قبلی و snapshot دیتابیس را برای rollback نگه می‌دارد. این جایگزین بکاپ مستقل نیست.
5. **خطر آشکار:** تغییرات شبکه، فایروال، SSL، فایل و سرویس باید هدف و اثرشان را روشن کنند.

## دامنهٔ پشتیبانی

نصب‌کننده برای Debian و Ubuntu مبتنی بر systemd طراحی شده است. ابزارها و نام بسته‌ها با نسخه و توزیع تفاوت دارند؛ پیش از اجرای عملیات تولیدی، VPS آزمایشی و snapshot سمت ارائه‌دهنده را ترجیح بده. ARG دسترسی SSH خارج از band را جایگزین نمی‌کند.

## نسخه و شاخه

`main` نسخهٔ پایدار است. `development` نسخهٔ پیش‌انتشار است و ممکن است رفتار یا API آن تغییر کند. در زمان نگارش، نسخهٔ پایدار `0.6.5` و نسخهٔ development `0.6.6-dev.1` است.
