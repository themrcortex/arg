## اجرای منو

```bash
sudo arg
```

با کلیدهای بالا و پایین حرکت کن، شمارهٔ گزینه را تایپ کن و Enter بزن. منو هنگام اجرا وضعیت سرویس، آدرس پنل و نسخهٔ شاخهٔ فعلی را بررسی می‌کند. گزینهٔ بروزرسانی پس از موفقیت، منو را مجدداً با نسخهٔ جدید اجرا می‌کند.

## دستورهای اصلی

| فرمان | کاربرد |
| --- | --- |
| `sudo arg` | بازکردن منوی تعاملی |
| `sudo arg status` | وضعیت systemd سرویس ARG |
| `sudo arg start` / `stop` / `restart` | کنترل سرویس پنل |
| `sudo arg logs [تعداد]` | نمایش گزارش سرویس؛ پیش‌فرض 100 خط |
| `sudo arg manage port` | تغییر پورت پنل از منو |
| `sudo arg ssl` | راه‌اندازی گواهی و TLS پنل؛ انتخاب سرویس‌دهنده در نصب‌کننده |
| `sudo arg update` | انتخاب شاخه و Cache و اجرای بروزرسانی |
| `sudo arg update main complete` | دریافت main و پاک‌سازی Cache قبل/بعد از Build |
| `sudo arg update development fast` | دریافت نسخهٔ آزمایشی و نگه‌داشتن Cache |
| `sudo arg cancel-update` | درخواست لغو Update فعال یا آزادکردن قفل مانده |
| `sudo arg rollback` | بازگرداندن باینری قبلی و snapshot دیتابیس قبلی |
| `sudo arg password` | بازنشانی رمز از دسترسی root |
| `sudo arg delete` | حذف سرویس با پرسش دربارهٔ نگه‌داشتن دیتابیس |
| `sudo arg delete --purge` | حذف کامل برنامه و داده‌ها پس از تأیید صریح |

عبارت‌های `main`, `development`, `fast`, `complete` را با حروف انگلیسی وارد کن. در فرم کوتاه Update، اگر شاخه یا روش Build را ندهی و TTY تعاملی باشد، نصب‌کننده آن‌ها را می‌پرسد.

## گزینه‌های منوی مدیریت

- **Install / repair:** نصب تازه یا بازسازی برنامه و سرویس. اجرای دوباره می‌تواند سورس را از شاخهٔ پیش‌فرض یا شاخهٔ ENV دریافت کند.
- **Service status:** وضعیت systemd، PID و گزارش وضعیت.
- **Start / Stop / Restart:** کنترل `arg.service`؛ Stop دسترسی پنل را قطع می‌کند اما سیستم‌عامل را خاموش نمی‌کند.
- **View service logs:** گزارش‌های `journalctl` برای عیب‌یابی.
- **Change panel port:** تغییر bind پورت و همگام‌سازی Firewall؛ از بازماندن SSH به‌عنوان راه برگشت مطمئن شو.
- **Configure HTTPS / SSL:** صدور گواهی، تنظیم Rust TLS یا ادامه با تنظیم دستی.
- **Update ARG:** انتخاب شاخهٔ Git، سیاست Cache، ساخت و نصب اتمیک با نگهداری نسخهٔ قبل.
- **Uninstall:** پاک‌کردن فایل‌های متعلق به ARG؛ می‌توان دیتابیس را نگه داشت.
- **Get one-time setup code:** کد راه‌اندازی مدیر اول، تا زمانی که مدیر ساخته نشده است.
- **Reset account password:** بازنشانی root بدون نیاز به رمز قبلی.
- **Cancel running update / Rollback:** کنترل Update یا بازگردانی آخرین نسخهٔ معتبر.

## کد خروج و گزارش‌ها

در اجرای SSH، خروجی استاندارد نصب‌کننده و خطای فرمان را حفظ کن. برای ثبت گزارش:

```bash
sudo arg update main complete 2>&1 | tee /tmp/arg-update.log
```

این فایل ممکن است خروجی کامپایل یا مسیرهای سیستم را داشته باشد؛ پیش از ارسال عمومی آن را بررسی و اطلاعات حساس را حذف کن.
