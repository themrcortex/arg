# بررسی اتصال، چرخش کلید و رفع ناسازگاری

## وضعیت سلامت Node

کارت Node وضعیت اتصال و سازگاری را جدا نشان می‌دهد. `healthy` یعنی آخرین درخواست امن موفق بوده؛ `degraded` یعنی ارتباط برقرار شده ولی عملیات یا پاسخ بخشی شکست خورده؛ `offline` یعنی ارتباط در دسترس نیست؛ `untrusted` برای رد شدن اعتبارنامه یا مجوز؛ و `incompatible` برای اختلاف قابلیت یا نسخه است. آخرین خطا و زمان بررسی روی همان کارت دیده می‌شود. اگر Node قدیمی باشد، امکانات خواندنی محدود می‌ماند و write نباید انجام شود.

## چرخش اعتبارنامه

روی دکمهٔ چرخش کلید کنار Node بزن. Controller یک کلید تصادفی را در پوشهٔ خصوصی `node-secrets` با مجوز محدود ذخیره می‌کند، آن را با HTTPS به مقصد می‌فرستد و پس از پاسخ موفق کلید فعال را جایگزین می‌کند. اگر پاسخ شبکه قطع شود، فایل `.pending` نگه داشته می‌شود تا تلاش دوباره همان کلید را استفاده کند. فایل را دستی باز، کپی یا پاک نکن و token خام را در گزارش‌ها قرار نده.

## تمدید نشست فضای کار

نشست remote پس از ۱۲ ساعت منقضی می‌شود. Controller هنگام دسترسی، اگر زمان کمی مانده باشد نشست scoped تازه می‌گیرد و آن را در فایل خصوصی جایگزین می‌کند. اگر تمدید موفق نشود، همان Node خطا می‌دهد؛ درخواست به سرور دیگری منتقل نمی‌شود. خطای `401` معمولاً به معنی نشست یا اعتبارنامهٔ منقضی است و `403` معمولاً یعنی scope انتخاب‌شده آن عملیات را مجاز نمی‌کند.

## رفع ناسازگاری

اگر پیام `Upgrade Required` دیدی، هر دو پنل را از منبع مورد اعتماد به‌روز کن. بعد در صفحهٔ Nodeها وضعیت را تازه‌سازی کن. اگر capabilityهای لازم هنوز ظاهر نشدند، اتصال را با تأیید لغو و دوباره با سطح دسترسی موردنظر Pair کن. Pair مجدد scopeهای جدید را صادر می‌کند؛ صرف تغییر نقش یا انتخاب workspace مجوز قبلی را گسترده نمی‌کند.

اگر وضعیت `untrusted` بود، نام Endpoint، گواهی TLS، تاریخ اعتبار کلید و فهرست scope را بررسی کن. `offline` را با `untrusted` اشتباه نگیر: اولی معمولاً شبکه یا سرویس خاموش است، دومی اعتبارنامه یا مجوز ردشده است.
