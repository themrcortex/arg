## Terms

| Term | Meaning |
| --- | --- |
| API | Structured interface for exchanging requests and responses |
| ARG helper | Separate root-level service that executes allowlisted operations |
| Audit | History of administrative events recorded by ARG |
| Bind address | Address/interface a service listens on; `127.0.0.1` is local, `0.0.0.0` is all IPv4 interfaces |
| Bucket | Object container in an S3-compatible service |
| Cache | Temporary data that can speed work but consume disk |
| cgroup | Kernel mechanism to measure or limit a process group |
| FUSE | Userspace filesystem; an S3 mount is not a complete POSIX disk |
| Image / Container | Docker template and its running instance |
| Listener | Socket waiting for connections on an address/port |
| Mount point | Path where Linux attaches a filesystem in its directory tree |
| Object / Prefix | S3 data and key; prefixes create folder-like naming only |
| Origin validation | Restriction of state-changing browser requests to expected origins |
| PTY | Pseudo-terminal for interactive shells and applications |
| Rollback | Restore a saved binary/database snapshot; not an independent backup |
| RPO / RTO | Target maximum data loss and recovery time |
| TLS | Transport encryption; HTTPS is HTTP over TLS |
| UFW | Simple netfilter firewall manager commonly used on Ubuntu/Debian |
| systemd unit | Linux service/timer definition and process policy |
