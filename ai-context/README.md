# Internal AI project context

This folder contains internal architecture notes, implementation status, and development plans for AI-assisted work on ARG. It is excluded from the bilingual end-user documentation site and must not be linked from public guides.

Treat roadmap entries as plans or audit notes, never as proof that a capability exists. Verify every implementation claim against the current source code before using it in product documentation.

# زمینهٔ داخلی پروژه برای AI

این پوشه شامل یادداشت‌های معماری، وضعیت پیاده‌سازی و برنامه‌های توسعه برای کار کمکی AI روی ARG است. محتوای آن در سایت مستندات کاربران منتشر نمی‌شود و نباید از راهنماهای عمومی به آن لینک داده شود.

موارد نقشه‌راه را برنامه یا یادداشت ممیزی بدان؛ نه مدرک وجود قابلیت. پیش از استفاده از هر ادعای پیاده‌سازی در مستندات محصول، آن را با کد فعلی بررسی کن.
